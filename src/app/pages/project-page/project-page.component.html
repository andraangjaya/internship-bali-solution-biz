Visora - Product Catalog Management

Visora Product Catalog Management merupakan aplikasi katalog produk yang digunakan untuk menampilkan dan mengelola informasi produk secara terpusat tanpa fitur transaksi atau pembelian. Aplikasi ini menyediakan dashboard admin untuk melakukan pengelolaan data produk seperti membuat, menghapus, dan edit produk. Sebagai Backend Developer, saya mengembangkan REST API menggunakan Laravel, termasuk menambahkan token-based authentication, authorization, validasi data, serta diintegrasikan dengan database untuk menyimpan data.

Mbagi - Berbagi Makanan Sisa

Mbagi merupakan platform website yang bertujuan mengurangi food waste dengan menghubungkan pihak restoran yang memiliki makanan sisa yang masih layak konsumsi dengan panti asuhan untuk memenuhi kebutuhan pangan mereka. Website ini memiliki fitur untuk menampilkan informasi donasi makanan, lokasi, serta detail distribusi yang sudah terjadwal. Website ini saya buat sebagai latihan mandiri diluar tugas dari perusahaan untuk memenuhi role Frontend Developer dengan menggunakan Angular dan Tailwind CSS.
